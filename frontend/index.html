TRANSPARENCY & GOVERNANCE

How this prototype works

Evidence, data processing, guardrails, and cross-provider price comparison.

01

Three billing formats

AWS, Azure, and GCP source-shaped toy CSVs have different column names. They are normalized and reconciled against one canonical billing dataset.

02

CPU + memory screening

Compute the observed 95th-percentile CPU and maximum sampled memory usage. Project utilization for smaller VMs. Reject unsafe candidates and treat missing memory as missing.

03

Policy-aware decisions

Identify possible savings through downsize or scheduled runtime. Surface unusual price increases. Honor the explicit cross-cloud migration restriction in demo customer policies.
